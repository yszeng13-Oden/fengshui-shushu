# 择日与配色

两块内容：**择日**（哪天适合做什么）和**配色**（当天穿什么颜色）。两者共用同一套底层——日柱与月令。

来源是传统黄历与日柱五行体系，属公开民俗，非某书独有。

---

# 第一部分：日柱与配色

## 一、底层逻辑

每天有一个**日柱**（天干 + 地支）。取色依据是**日干的五行**，但**必须叠加日支和月令**来判断日主的强弱，不能只看天干。

这是本节最核心的一条，也是最容易做错的一条：**只看日干的取色是残的。**

## 二、推算步骤

**第一步，算日柱。**

用儒略日（JDN）推干支，可靠且可复算：

公式：`干支序 = (JDN + 49) mod 60`，其中 0 为甲子。

**校验锚点**（务必用这两个对一下，算错就全错）：
- 1949-10-01 → **甲子日**
- 2000-01-01 → **戊午日**

**第二步，看日干五行。**

甲乙木、丙丁火、戊己土、庚辛金、壬癸水。

**第三步（关键），看日支与月令定强弱。**

- **日支**：看它对日干是生扶还是克泄。如壬水坐戌土 → 土克水，弱；癸水坐亥水 → 亥为癸之帝旺，旺
- **月令**：出生月的地支决定当月的"当令之气"。如戌月土当令，全局土气重，会压制其他五行

**第四步，按强弱定策略。**

| 日主状态 | 策略 | 取色倾向 |
|---|---|---|
| **弱** | 扶（生我、同我） | 优先用生我之色（印）和同我之色（比劫） |
| **旺** | 泄 / 耗 | 用我生之色（食伤）泄秀；我克之色（财）为次 |

**第五步，查颜色五行。**

**金**：白、银、米白、浅灰、金
**水**：黑、深蓝、藏青、深灰、灰
**木**：绿、青、墨绿、竹青
**火**：红、酒红、紫、粉、橙
**土**：黄、棕、卡其、驼、米黄、褐

**第六步，出结论。**

按"大吉 / 次吉 / 平 / 用或少用 / 避开"五档给出，并落到**具体部位**（上衣、下装、鞋、配饰），不要停在"多穿白色"。

## 三、四种基本关系

以日干为中心：

**生我（印）** —— 如金生水。这是**最优先**的，主滋养、有靠山。
**同我（比劫）** —— 如水与水。同气相助，稳，是**底色**。
**我生（食伤）** —— 如水生木。**日主旺时用**，主表达、顺畅、出行利；日主弱时是泄气，不利。
**我克（财）** —— 如水克火。主财与机会，**适合办正事、见人**；日主弱时克不动，反成负担。
**克我（官杀）** —— 如土克水。**避开**，主压力、受制。

## 四、常见误区

**误区一：只看日干。** 前面已说，这是最主要的错误。同为水日，壬戌（弱）该扶、癸亥（旺）该泄，建议相反。

**误区二：忽略月令。** 日柱是"当天的主角"，月令是"当月的背景"。戌月里即使日干属木，土气仍在，黄棕色仍要慎用。**背景不能略过。**

**误区三：颜色只分五种。** 实际搭配要考虑明度与饱和度。深蓝和浅蓝同属水，但深蓝更"实"、浅蓝更"轻"，正式场合与休闲场合的选法不同。

**误区四：把民俗禁忌当数理。** "4 不吉利"是谐音民俗，不是五行数理（4 属金，本身无吉凶）。讲的时候要分开，别混为一谈。

## 五、必须声明的边界

**这套推法只用日柱，不结合个人八字，属通用版。** 回答时必须讲明这一点，并提议：若用户提供**出生年月日 + 性别**，可算个人喜用五行，给出专属配色，比通用版准。

**配色属民俗层面的软建议。** 不要把它说成能改变运势。它真实的用处是：给每天一个仪式感的锚点、减少选择成本、心理上有个"今天准备好了"的感觉。这个作用不值得贬低，但也不该夸大。

**穿什么最终还要看场合、天气、肤色。** 十月的北方和南方的选法不同。术数给的是五行层面的倾向，不是着装方案的全部。

# 第二部分：黄历择日

## 一、日柱之外要看什么

黄历一天的吉凶由多项叠成，常用的有四项：**十二建除、黄道黑道十二神、二十八宿值日、日冲日煞**。

四项各有侧重，**同一项里吉、另一项里凶是常态**——不要因为一项凶就说"今天不能办事"。

## 二、十二建除

**顺序固定**：建、除、满、平、定、执、破、危、成、收、开、闭。

**推法**：在**节月**内（注意以节气分月，不是农历月），**与月建同支的那一天为"建日"**，其后逐日顺排。

例：戌月（寒露至立冬），戌日为**建日**，则亥日为除日、子日为满日，依此类推。

**吉凶**（通行的口径）：

| 建除 | 吉凶 | 宜 |
|---|---|---|
| **建** | 吉 | 出行、上任、祈福；忌动土、开仓 |
| **除** | 吉 | 除旧、疗病、扫舍、出行 |
| **满** | 吉 | 祈福、嫁娶、开市；忌服药、栽种 |
| **平** | 平 | 平常之日，宜修饰、平治；忌大事 |
| **定** | 吉 | 嫁娶、订盟、入宅、安床 |
| **执** | 吉 | 捕捉、立约、造屋；忌出行、开市 |
| **破** | **大凶** | 诸事不宜，只宜破屋、求医 |
| **危** | 凶 | 宜安床、祭祀；忌登高、出行、嫁娶 |
| **成** | 大吉 | 嫁娶、开市、入宅、入学，诸事皆宜 |
| **收** | 平 | 宜收纳、进财；忌开市、出财 |
| **开** | 大吉 | 开市、入学、出行、动土，诸事皆宜 |
| **闭** | 凶 | 宜埋葬、修整；忌开市、出行、开渠 |

**"成、开"两日最吉，"破、闭"两日最忌**，这是最常用的两条。

## 三、黄道黑道十二神

**顺序固定**：青龙、明堂、天刑、朱雀、金匮、天德、白虎、玉堂、天牢、玄武、司命、勾陈。

**黄道（吉）**：青龙、明堂、金匮、天德、玉堂、司命 —— **六吉**
**黑道（凶）**：天刑、朱雀、白虎、天牢、玄武、勾陈 —— **六凶**

**推法**：以**月支**定起点，顺排十二神到日支。各月的起点不同（如戌月自青龙起于戌），口诀是"青龙起例"一系的月家起法。

**这条比建除更常被引用**，日常说"今天是黄道吉日"指的就是它。

## 四、二十八宿值日

**二十八宿**分四象，各七宿：

- **东方青龙**：角、亢、氐、房、心、尾、箕
- **北方玄武**：斗、牛、女、虚、危、室、壁
- **西方白虎**：奎、娄、胃、昴、毕、觜、参
- **南方朱雀**：井、鬼、柳、星、张、翼、轸

**推法（简化口径）**：以甲子日起角宿，逐日顺排一轮二十八天。

**吉宿**：角、房、尾、箕、斗、室、壁、娄、胃、毕、参、井、张、轸
**凶宿**：亢、氐、心、女、虚、危、奎、昴、觜、鬼、柳、星、翼

**说明**：二十八宿值日各派起法有出入（有按星宿度数的严格推法），本 skill 用的是"甲子起角"的简化口径，日常够用。**如果用户要精细择日，先说明这是简化法。**

## 五、日冲与日煞

**日冲**：日支与某生肖相冲，那天该生肖的人诸事不顺。**六冲为**：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

例：**戌日冲辰**，属龙的人那天要留意。（2026-10-15 壬戌日，即冲龙。）

**日煞**：日支所煞之方，忌动土、出行。**三煞**为最重：

- **申子辰日煞南**
- **寅午戌日煞北**
- **亥卯未日煞西**
- **巳酉丑日煞东**

（2026-10-15 壬戌日属寅午戌组，**煞北**，正北方不宜动土。）

## 六、综合取用的次序

四项堆在一起会有矛盾，按这个顺序取：

**一票否决**：**日冲本人生肖**时，不管其他项多吉，这天不宜办大事。
**重权重**：**破日、闭日**（建除）+ **黑道**（十二神）—— 两者同凶，最需回避。
**加分项**：**成日、开日** + **黄道**，是理想组合。
**参考**：二十八宿与日煞作为辅助，不作为决定性因素。

## 七、择日实务

**嫁娶**：优先成日、开日、定日 + 黄道；**必须避开新人双方的生肖冲日**；再看二十八宿。
**开业**：宜开日、成日、满日；忌破日、闭日。
**入宅搬家**：宜定日、成日、开日；避日煞方（搬入当天不宜往煞方走）。
**动土装修**：**先看流年五黄位**（见 `references/bashuxiang.md`），五黄方绝不动；再选成日、开日；避开日煞方。
**求医问诊**：宜除日；忌满日（满日忌服药）。
**出行**：宜建日、除日、开日；忌危日（危主登高涉险）。

**注意**：日常使用可以简化到"避开双方冲日 + 选黄道 + 避破日"三条。**要说清这是简化口径**，精细择日涉及更多神煞，非本 skill 覆盖范围。

## 八、必须声明的边界

**择日是民俗，不是科学决定论。** 一件重要的事能不能成，取决于准备、时机和运气，不取决于挑了哪天。择日真正的作用是**帮人下定决心、减少犹豫**——这个作用是真的。

**不要吓人。** 说"这天不宜"，要给替代方案（"这周还有哪几天合适"），不要只丢一句"不吉"让人无所适从。

**涉及医疗、法律、投资的择日建议，必须说明这只是民俗参考**，真正的安排要听专业人士的。
