# 案例模板

复制本文件，重命名为 `编号-主题.md`，按下表填写。**填不出来的栏位就写"缺"，不要编。**

---

## 编号-主题

**日期**：YYYY-MM-DD
**涉及模块**：（八星风水 / 小六壬 / 姓名学 / 识人象数 / 择日 / 复合）

### 一、用户的问题（原话）

> 把用户原话抄下来。原话很重要——提问的具体程度、他真正在意什么，往往藏在措辞里。

### 二、输入信息

| 项 | 值 |
|---|---|
| 出生年份 / 性别 | |
| 生辰八字 | （有则填，注意时辰是否确定） |
| 房子入住年份 | |
| 坐向 / 大门朝向 | |
| 户型关键点 | （卧室、卫生间、厨房的方位） |
| 其他 | |

**缺哪些关键信息**：
**当时是否追问了**：是 / 否，追问后拿到了什么

### 三、定盘（把算式写出来）

逐步推演，每一步都写清楚用了哪条规则：

1. 命卦：`……` → `X命`
2. 宅卦：
3. 八方八星：
4. 其他（日柱 / 起课 / 笔画）：

### 四、判断

**落点**：吉方是哪些、凶方是哪些

**冲突与优先级**：这是本栏的核心。把互相打架的条件列出来，写清**为什么这样排序**。

> 例：大门在绝命（凶），但主卧在生气（吉）。门管进气与动线，是"每天都要过"的；床管休息恢复。两者性质不同不互相抵消，所以处理顺序是先看门能不能化，再看床位会不会被压。

### 五、给出的建议

分"避 / 化 / 改"三层写，落到具体位置和物件。

### 六、当时的犹豫

**这一栏最有价值，别省。** 记录：
- 哪一步没有把握
- 哪个信息缺失导致只能给保守判断
- 有没有两派说法不一致、你选了哪一派、为什么

### 七、结论与应验

**回访结果**：应验 / 部分应验 / 不应验 / 未回访 / 无法判断

**偏差分析**：如果不应验，是输入错了、推演错了，还是方法本身的局限？

## 填写提醒

**别只记结论。** 一份只有结论的案例，三个月后你自己都看不懂为什么这么断。

**别美化。** 不准的就写不准。案例库变成"自夸集"就没用了。

**原话抄下来。** 用户真正的问题常常和他问的不一样——"这个房子好不好"背后可能是"我最近一直不顺"。原话能留住这个线索。
