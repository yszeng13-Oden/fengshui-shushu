# 001-门吉卧吉却问权衡

**日期**：2026-10-16
**涉及模块**：八星风水（八宅）

## 一、用户的问题（原话）

> 我家大门朝东南，主卧在东北，2019 年入住的，这样摆行不行？

## 二、输入信息

| 项 | 值 |
|---|---|
| 出生年份 / 性别 | 1985 年，男 |
| 房子入住年份 | 2019 年 |
| 坐向 / 大门朝向 | 大门朝东南，即坐西北朝东南 |
| 户型关键点 | 主卧在东北；未提供卫生间与厨房方位 |
| 其他 | 未给楼层，按普通楼层处理 |

**缺哪些关键信息**：卫生间、厨房、灶位方位全部缺失。
**当时是否追问了**：追问了卫生间方位，用户未答。因此卫生间是否占吉方**无法判断**，需在结论中标注。

## 三、定盘

**第一步，算命卦。**

1985 年男：1+9+8+5=23 → 2+3=5 → 男命 11−5=6 → 6 为乾 → **乾命**（西四命）

**第二步，算宅卦。**

大门朝东南 = 坐西北朝东南 = **乾宅**（西四宅）

**第三步，看东西四宅是否相配。**

乾命（西四命）住乾宅（西四宅）—— **相配，这是好底子**。

**第四步，查八方八星**（以乾为伏位，查八宅游年表）：

| 方位 | 星 | 吉凶 | 五行 |
|---|---|---|---|
| 西北 | 伏位 | 平 | —— |
| 东北 | 生气 | 大吉 | 木 |
| 东南 | 延年 | 吉 | 金 |
| 西南 | 天医 | 吉 | 土 |
| 正北 | 祸害 | 凶 | 土 |
| 正东 | 六煞 | 凶 | 水 |
| 正西 | 五鬼 | 大凶 | 火 |
| 正南 | 绝命 | 大凶 | 金 |

**第五步，落点。**

- 大门在**东南 = 延年**（吉）→ 门落在吉方，非常好
- 主卧在**东北 = 生气**（大吉）→ 床落在最旺的方，非常好

## 四、判断

**用户问的"这样摆行不行"，答案是：相当好，属于少见的两头都占。**

门在延年、卧在生气——这是八宅法里最理想的几种组合之一，且命卦与宅卦同为西四，三样全对。

**但要说清一件事，用户的原话里其实有个误解。** 他问"这样摆行不行"，隐含的假设是"门和卧是两个可以互相权衡的因素"。**实际上它们性质不同，不互相抵消，各有各的管法**：

- **门**管进气与动线，是全屋的"入口"。门在延年，主的是——人际和顺、婚姻与外部关系顺畅、有贵人往来。
- **卧**管休息与恢复。卧在生气，主的是——精力足、身体恢复好、做事的底气足。

两者各管一摊，不存在"门凶所以卧吉也白搭"这种情况。这也是本案例值得归档的原因：**用户以为要权衡，实际不需要权衡；真正需要提醒的是他自己的另一个假设——"是不是摆好就没事了"。**

**顺带一提，他没问但值得说的**：命卦与宅卦都是西四，这是"人宅相配"。如果他将来搬家，新房子还是尽量挑坐西北（乾）、坐西（兑）、坐东北（艮）、坐西南（坤）这几向的，别换到东四宅去。

## 五、给出的建议

**避 / 化**：无凶位需要处理（已知的方位里没有凶星落点）。

**用起来（这是关键）**：

- **东北生气方（主卧）**：床头朝生气方或背靠实墙。生气属木，可用绿色、木质元素强化。务必**不要在东北方堆杂物、放垃圾桶**——吉方最怕被压、被污。
- **东南延年方（大门）**：保持通畅、明亮、整洁。延年属金，可用白色、金属质感物件（鞋柜、门把手）。**门内不要堆鞋和杂物**。
- **西南天医方**：适合放药箱、健身器材、常喝的茶水，对健康有利。

**要提醒的一句**：**生气方（东北）最忌被卫生间压**。这是本案例最大的未验证项——用户没给卫生间方位。如果卫生间正好在东北，那刚才说的一切都要推翻重算，因为"厕占吉方"比凶方摆放的伤更大。

## 六、当时的犹豫

**第一，卫生间方位拿不到，结论只能是条件性的。** 我选择先给出"假设卫生间不在东北/东南"的完整判断，再明确标出这个前提。没有拿这个去反复追问，因为用户看起来只想要个"行不行"的定性答复。

**第二，"这样摆行不行"要不要翻译成术数语言。** 用户的问法很含糊。我判断他真正想知道的是"我这房子算好还是不好"，所以按"门 + 卧 + 人宅相配"三项综合给结论，而不是逐项罗列规则。

**第三，要不要提"搬家看朝向"这件事。** 用户没问搬家，提了显得多余。但它属于"同一组知识的下一次应用"，说了对用户有实际价值，所以放在最后一句，不占主干。
